## 状態

- 10/13〜10/23、毎日02:00日本時間で11本予約済み。公開済みの自己紹介1本はユーザー申告。
- 自動制作はPAUSED。予約済み投稿はMeta側で維持。新規制作・追加予約はユーザーの再開依頼後。
- 最適な投稿時間、成長率、予約数の効果は未実証。48時間／7日後の結果を記録して改善する。
- Gitで変更してもInstagramプロフィールや予約内容は自動更新されない。Metaで変更してから記録を更新する。

## 制作・更新の流れ

1. 原本素材の画質・撮影場所・日時・料理名・掲載可否を確認する。
2. 正確な情報と1つの役立つテーマを選び、映像・字幕・本人の声を編集する。
3. スマホで字幕、映像との一致、音量、最後の画面を確認する。
4. ユーザーの依頼範囲を確認して投稿または予約し、Metaの一覧で日時・アカウントを読み戻す。
5. planとキャプションを更新。完成素材は次のReleaseへ。古い配布は履歴として残す。

原本の写真・動画はローカル管理。完成素材ZIPの動画を再編集できるが、レイヤーや元素材を含むプロジェクトファイルではない。元素材が必要な作業では、別途ユーザーから対象原本を共有してもらう。
