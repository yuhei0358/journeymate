# 01 / 品質を上げる優先順位

## 現時点の課題

投稿できる形は整ったが、まだ素材の幅と本人らしさが弱い。屋台の同じ場面や写真が繰り返され、今回の追加7本には本人のナレーションがない。固定した情報カードは読みやすい一方、余白が多く、臨場感とテンポは改善できる。フォロワー増や予約への効果はまだ未計測。


| 優先 | 改善すること | 具体的な実施案 |
| --- | --- | --- |
| 1 | 元素材の品質・種類 | 縦の原本動画を追加。料理の寄り、屋台外観、街歩き、店主の手元、Yuhei本人の説明を撮る。 |
| 2 | 最初の1〜2秒 | 料理の動きや本人の顔から始める。1本につき「見る理由」を1つに絞る。 |
| 3 | 本人の声と信頼 | 短い英語ナレーションを録音。自分のおすすめ理由や体験を具体的に話す。 |
| 4 | 編集と文字量 | 短いカットを組み合わせる。字幕は1画面1要点。写真は低解像度を無理に拡大しない。 |
| 5 | 情報の正確さ | 料理名・価格・営業時間を確認。過去写真のメニューや価格を現在の情報として扱わない。 |

## 次に撮ると効果が高い素材

・料理：湯気、麺上げ、焼き音、盛り付け。各5〜8秒を3種類。
・移動：駅出口から屋台までの目印、昼と夜の街、雨の日の代替案。
・本人：顔が見える状態で「誰におすすめか」「よく聞かれる質問」を各15〜20秒。
・会話：案内している場面や店主とのやり取り。撮影・掲載の了承を確認してから使う。

## 撮影の共通仕様

縦9:16、1080p以上の原本、安定した構図、明るい顔、聞き取りやすい音。アプリで圧縮した共有画像より元ファイルを優先する。各素材に場所・撮影日・料理名・掲載可否を添える。撮影時に数秒長めに回し、編集の余地を残す。

## 公開の基準

文字がスマホで読める／最初から最後まで映像と説明が一致する／1つ役に立つことがある／保存・フォローする理由がある。この基準に達しない素材は、本数を増やすために公開せず保留する。

# 02 / フォロワーと集客の育て方

## 投稿の役割を分ける


| 役割 | 内容の例 | 見たい反応 |
| --- | --- | --- |
| 発見される | 調理の臨場感、短いPOV、地域の意外な食文化 | 非フォロワーへの到達、視聴時間 |
| 保存される | 注文の言葉、交通、雨天対策、1日旅程 | 保存、シェア |
| 信頼される | Yuheiの顔・声、案内の考え方、実際のツアーの流れ | プロフィール閲覧、フォロー |
| 相談につながる | 誰向けのツアーか、内容、所要時間、対応言語 | 具体的な問い合わせ、予約 |

## 最初の検証方法

各投稿の公開48時間後と7日後に、再生・平均視聴時間・リーチまたは利用可能な閲覧者指標・保存・シェア・プロフィール閲覧・フォロー増を記録する。表示されない指標は「未取得」とする。投稿ごとのフォロー帰属が見えない場合、期間全体の増分と混同しない。

保存・シェアは可能ならリーチで割って比較する。フォローへの転換は取得できる範囲で比較し、再生数だけで判断しない。少数の投稿では内容・曜日・視聴者の違いが大きいため、「深夜2時が最適」「毎日投稿で伸びた」と早期に断定しない。次の検証では時間か編集形式など、主な変更を1つに絞る。

## 訪日外国人向けツアーへの接続

目的は、日本でYuheiさんが行う訪日外国人向けツアーに集客すること。福岡・九州の役に立つ情報を入口に、地元ガイドとしての人柄・知識・案内する価値を伝える。英語で旅行を計画する海外の人と、すでに日本に滞在している旅行者の双方を意識する。

1. 保存したくなる旅行情報で発見され、プロフィールでYuheiさんの顔・活動場所・案内の価値を伝える。
2. ツアーの雰囲気、案内する場面、参加者に合う旅のタイプを紹介し、ガイドを頼む理由を示す。
3. 既存ツアーの対象者・集合場所・所要時間・料金・対応言語・予約方法を最新情報にそろえる。
4. 準備が整ったら、プロフィールに案内ページを設置し、投稿 → プロフィール → ツアー詳細 → 問い合わせ／予約へつなぐ。

予約導線を作る前に、連絡窓口と実際の対応を整える。実行できないDM資料送付や未確定のサービスを約束しない。フォロワー数だけでなく、旅行予定のある人からの具体的な相談を重視する。
